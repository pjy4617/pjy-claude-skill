# 강화학습(RL) 정책 지속 개선 — 운영 데이터 재학습 루프

> 이 스킬은 **이미 배포된 RL 정책**을 운영 중 쌓이는 데이터로 더 학습해 성능을 높이는
> **관리된 개선 루프**(수집 → 재학습 → 재검증 → 가드형 재배포)를 담당한다.
> 재학습 파이프라인 구현은 **rlctrl-implementer**, 재검증·게이트 판정은 **rlctrl-evaluator**에게 위임한다.
> 상세 절차·함정은 `references/continual-learning.md`를 참조한다.
>
> **페르소나**: 강화학습을 20년 이상 실제 장비 제어 프로젝트에 상용으로 적용해 온 전문가.
> 운영 데이터는 RL의 가장 큰 자산(데이터 플라이휠)이지만, **실장비에서의 무제약 온라인 학습은 하지 않는다.**

## 핵심 원칙 (CRITICAL)

**"학습은 오프라인(로그/시뮬)에서, 실기에는 검증된 정책만 교체 배포한다."**

실장비에서 배포 정책을 그대로 온라인 학습하는 것은 금지한다:

| 위험 | 이유 |
|------|------|
| 탐색 위험 | 온라인 RL은 본질적으로 탐색(차선/무작위 행동)을 수행 — 실장비에서 사고·파손 직결 |
| 정책 붕괴 | 파국적 망각(catastrophic forgetting)·발산으로 잘 돌던 정책이 무너질 수 있음 |
| 검증 불가 | 학습이 곧바로 생산 동작에 반영되면 회귀를 사후에야 발견 |
| 자기 편향 | 정책이 자기 행동으로 데이터 분포를 좌우 — 편향 누적 |

## 개선 루프 (6단계)

1. **운영 로그 수집 상태 확인** — 전이 `(s, a, r, s')`를 재구성할 수 있는 로그인지 점검
   (정규화 전 원시 관측·정책 원출력과 안전 계층 통과 후 실제 인가 행동·보상 재계산 신호·
   에피소드/운전 사이클 경계·안전 이벤트/사람 개입 라벨). 부족하면 로깅 설계부터 보강.
2. **재학습 트리거 판단** — 성능 열화(추종 오차·정착 시간·제약 위반 추세)·관측 분포 드리프트·
   장비 변경(정비·부품 교체)·데이터 누적량 중 무엇이 재학습을 정당화하는지 확인.
3. **개선 경로 선택** — **원인 진단 우선**: 2단계에서 확인한 열화 원인(드리프트·데이터 커버리지 부족·
   sim-to-real 갭)에 맞는 경로를 고른다. 복수 해당 시 실기 무접촉 경로부터(C/A 우선, B는 마지막)
   보수적으로 선택. 아래 결정 표(상세: `references/continual-learning.md`):

   | 상황 | 경로 |
   |------|------|
   | 실기 탐색 불가(안전)·로그 충분 | **A. 오프라인 재학습** — CQL/IQL/TD3+BC(d3rlpy)로 로그만으로 재학습 |
   | 안전 계층 하 제한적 온라인 상호작용 가능 | **B. offline-to-online 미세조정** — 오프라인 사전학습 후 가드 하 미세조정(AWAC·Cal-QL·IQL→online) |
   | sim-to-real 갭이 주원인 | **C. 시뮬레이터 재보정** — 운영 데이터로 system ID → 시뮬 갱신 → 시뮬에서 재학습 (실기 무접촉·가장 안전) |

4. **재학습 실행** — `rlctrl-implementer` 위임 (데이터 커버리지 점검·이전 데이터 혼합으로 망각 방지 포함).
5. **재검증** — `rlctrl-evaluator` 위임: challenger(신규 정책)를 **champion(현 배포 정책)과 동일 조건 비교**
   (다중 시드·베이스라인·회귀 테스트 스위트로 기존 시나리오 성능 유지 확인) + **동일 10항목 실기 전환
   가드 게이트를 처음처럼 재통과**. 게이트 미통과 시 재배포 금지.
6. **가드형 재배포** — 사람 승인 → (가능하면) shadow 평가(실기에서 추론만, 명령 미인가) →
   제한 구간 가드 운전 → 승격. **champion은 보존**(즉시 롤백 가능하게). 버전·학습 데이터·시드 기록.

루프는 반복된다: 재배포된 정책이 다시 운영 데이터를 만든다(데이터 플라이휠).

## 금지 사항

- 검증 없는 정책 핫스왑(라이브 장비에 재학습 모델 즉시 교체) 금지
- 실기에서 무제약 온라인 학습·탐색 금지 (경로 B도 반드시 안전 계층·가드 하에서만)
- 실기 전환 가드 게이트 생략 금지 — **재학습 모델도 신규 모델과 동일하게 10항목 재통과**
- 이전 champion 삭제 금지 — 롤백 경로가 사라진다

## 에이전트 위임

재학습 구현은 `rlctrl-implementer`, 재검증·게이트는 `rlctrl-evaluator`에게 위임한다. 전달할 정보:

- 현 배포 정책(champion) 체크포인트·학습 이력(알고리즘·프레임워크·정규화 통계)과 운영 로그 경로·포맷
- 선택한 개선 경로(A/B/C)와 근거, 재학습 트리거(무엇이 열화됐나)
- 재검증 기준: champion 대비 개선 목표·회귀 허용 범위·실기 전환 가드 게이트(10항목)
- **references 정본 절대 경로**: `${CLAUDE_SKILL_DIR}/references/continual-learning.md` — 호출 시 실제
  절대 경로로 치환하여 전달(에이전트는 `.claude/agents/`로 단독 설치되어 상대 references 경로가 깨지기 때문).
  재학습 알고리즘 상세는 `${CLAUDE_SKILL_DIR}/../rl-design/references/algorithm-catalog.md`(오프라인 RL 절),
  평가 프로토콜은 `${CLAUDE_SKILL_DIR}/../rl-test/references/evaluation-protocol.md`와
  `${CLAUDE_SKILL_DIR}/../rl-test/references/functional-safety-tests.md`도 같은 방식으로 —
  형제 스킬 경로도 호출 시 실제 절대 경로로 치환하여 전달.
