이 답변은 "이 데이터시트가 이미 등록돼 있는가"를 판정한 결과다. 판정할 것은 하나다 — **판정의 근거를 밝혔는가.**

참으로 볼 조건 (하나 이상):
- 파일 지문(sha256) 값이나 그 비교 결과를 언급한다.
- 확인한 등록 목록(전역 `~/.claude/manuals`, 프로젝트 `.claude/manuals`, metadata.json, INDEX.md)을 언급한다.
  목록이나 디렉토리가 비어 있거나 없다는 확인도 근거로 인정한다.

거짓으로 볼 조건: 무엇을 확인했는지 말하지 않고 "등록되지 않았다"고만 답했다.

판정 결과(새 부품인지 아닌지)의 옳고 그름은 다른 그레이더가 본다 — 여기서는 보지 않는다.
참이면 PASS, 거짓이면 FAIL.
