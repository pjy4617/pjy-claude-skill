하드웨어-펌웨어 성격에 맞게 분해됐는지, **분해 축과 순서**만 본다.
규모 표기와 XL 잔존은 별도 정규식 채점자가 판정하므로 여기서 다시 보지 않는다. 모두 만족해야 통과.

- 회로/부품 설계, 아트웍(PCB 레이아웃)·제조, 펌웨어 브링업, 검증이 각각 별도 TASK로 나타난다. 이 네 갈래 중 둘 이상이 한 TASK에 뭉쳐 있으면 실패.
- 구현 TASK와 검증 TASK가 분리돼 있다(같은 TASK 안에서 만들고 스스로 확인하는 구성이 아니다).
- 아트웍·제조·브링업의 선행 관계가 실제 순서대로 잡혀 있다(예: 회로 확정 없이 아트웍이 착수 가능으로 표시돼 있지 않다).
